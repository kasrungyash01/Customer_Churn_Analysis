# Customer Churn Analysis using Python

## Overview

Customer churn is one of the most important business challenges across industries. This project focuses on analyzing customer data to identify factors influencing customer churn and developing machine learning models to predict customers who are likely to leave.

The project follows an end-to-end data analytics and machine learning workflow, including data cleaning, data integration, exploratory data analysis (EDA), statistical analysis, feature engineering, data preprocessing, predictive modeling, and model evaluation.

The goal is to help businesses improve customer retention by generating actionable insights from customer data.

---

## Dataset

The project utilizes three Excel datasets:

* **customer_data.xlsx** – Customer demographic and account-related information
* **performance_data.xlsx** – Customer engagement and performance metrics
* **additional_data.xlsx** – Additional customer attributes and supporting information

These datasets were merged to create a comprehensive dataset for customer churn analysis and prediction.

## How to Run

### Prerequisites

* Python 3.x
* Jupyter Notebook

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn openpyxl
```

### Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/customer-churn-analysis.git
```

2. Navigate to the project directory

```bash
cd customer-churn-analysis
```

3. Launch Jupyter Notebook

```bash
jupyter notebook
```

4. Open and run:

```text
Data_Analysis_Python.ipynb
```

5. Execute all notebook cells sequentially.
