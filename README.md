# Customer Churn Analysis in Jupyter Notebook

## Overview

This project focuses on analyzing customer data to identify factors that contribute to customer churn and build predictive machine learning models. The project follows an end-to-end data analytics workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, statistical analysis, data preprocessing, and predictive modeling.

The objective is to help businesses understand customer behavior, identify at-risk customers, and improve customer retention strategies through data-driven insights.

---

## Dataset

The project uses the following datasets:

* **customer_data.csv** – Customer demographic and account information
* **performance_data.csv** – Customer performance and engagement metrics
* **additional_data.csv** – Additional customer-related attributes

These datasets were merged and analyzed to create a unified dataset for churn prediction.

## How to Run

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

### Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/customer-churn-analysis.git
```

2. Open Jupyter Notebook

```bash
jupyter notebook
```

3. Run:

```text
Data_Analysis_Python.ipynb
```

4. Execute all notebook cells sequentially.
